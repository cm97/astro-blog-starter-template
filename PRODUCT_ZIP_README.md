## What each file does

**01-onboarding/** — Everything from signed contract to first deliverable. The checklist, the intake form, the kickoff agenda. Run it once, it works forever.

**02-weekly-planning/** — The 20-minute reset that keeps your week from collapsing. Monday setup, Friday review. Short. Repeatable.

**03-follow-ups/** — Three email templates that get replies. The cadence that doesn't feel spammy. The breakup email that actually works.

**04-scope-and-proposals/** — The exact words to say no without losing the client. The proposal structure that closes. The pricing worksheet so you stop guessing.

**05-retention/** — How to keep clients from ghosting. The re-engagement email for when they go quiet.

## How to use it

1. Download the zip.
2. Unzip it.
3. Read the README (this file).
4. Pick one checklist. Run it this week.
5. Don't try to do all of it at once. That's how it dies.
