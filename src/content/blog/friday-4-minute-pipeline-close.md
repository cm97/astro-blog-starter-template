Friday afternoon. Open proposals still sit. One deposit is unpaid. A mid-project client has not replied to the draft you sent Wednesday. You tell yourself you will handle it Monday. Monday starts with a scramble and the threads are already cold.

That weekend gap is where money dies. Not because the work is hard. Because the next action only lives in your head.

Run this 4-minute close every Friday before 3pm. Same rows. Same note. Same outcome: either a send goes out today or the item is parked with a Monday date.

## The 4-minute Friday scan

Open the same note you use for the Monday reset. Write these four rows. Cap each at three names. More than that is noise.

```
Proposals past 48 hours, no reply: ________  ________  ________
Deposits unpaid past day 2: ________  ________  ________
Clients quiet mid-project past 5 days: ________  ________  ________
Final invoices unpaid past 7 days: ________  ________  ________
```

Four minutes. Do it standing up if you have to. If a row is empty, write none. Blank means you will invent it later.

## The one exact note you send (or schedule)

Pick the highest-cash row. Send or schedule this single line before you close the laptop. Not a new paragraph. Not a novel.

For a quiet proposal:

> Still holding [start date] until Monday. Reply with one line if you want me to keep the slot.

For an unpaid deposit:

> Deposit link again: [link]. I can start on [date] once it clears. Reply if the date needs to move.

For a mid-project quiet:

> Need [specific item] to keep [next deliverable] on [date]. Reply with it or a new date and I will lock the rest.

For a final invoice:

> Final invoice is still open. Reply with the payment date or a question and I will close the project on Monday.

Subject stays the original thread. Send before 3pm. Log the time in the same note. Do not check again until Monday morning.

## Exact fill-in you paste

```
Highest-cash row: ________
To: ________
Subject: Re: ________
Body: [one of the four lines above]
Sent / scheduled: ________
Monday action if silent: park / close / one more line
```

## What you do with the rest of the rows

- Write the Monday date next to each remaining name. That is the only action. No second email today.
- Cap open rows at eight total. Anything older than the day count above gets parked or closed before you leave.
- If nothing is on the list, write "none" and close the note. You are done.

## Extra steps that keep the weekend from erasing the work

1. Run the scan at the same clock time every Friday. Unscheduled closes die.
2. Keep the four template lines in the same note as the Monday reset. One open, all ready.
3. Never send after 3pm. Move those to Monday morning instead.
4. Screenshot or copy the note into the weekly reset card the same hour. Blank next action means the thread dies again.
5. On Monday, open the same note first. The Friday close is the input to the 20-minute reset.
6. If a client replies over the weekend, answer in one sentence and restate the original date. Do not open new scope.
7. Cap at one send on Friday. A second becomes noise and you start negotiating with yourself.
8. At the next weekly reset, add a row: "Friday closes that still need a Monday line." If none, write none.
