This theme comes with basic styles for typography and other elements — all crafted to match the kitschy-cozy aesthetic of the blog. Use this page as a reference for how your Markdown content will look.

## Headings

Use headings to break up long sections. This helps readers scan and find what they need.

### Sub-headings

Sub-headings work the same way. Nest them under main headings to create a clear hierarchy.

## Emphasis

**Bold** and *italic* text draw attention to key points. Use them sparingly so they still stand out.

## Lists

- First item
- Second item
- Third item

1. Numbered list
2. Keeps things organized
3. Easy to follow

## Blockquotes

> Pull quotes or important notes can be highlighted with blockquotes.

## Code

Inline `code` and fenced code blocks are supported:

```js
console.log('Hello, world!');
```

## Images

Images are centered and responsive. Add captions with the standard Markdown syntax.

## Tables

| Feature | Supported |
| --- | --- |
| Headings | Yes |
| Lists | Yes |
| Code blocks | Yes |
| Tables | Yes |

## Horizontal Rule

A horizontal rule creates a clean break between sections.
