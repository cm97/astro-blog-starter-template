They paid. You feel the relief. Then Thursday arrives and you still haven't sent the welcome email or locked the first deliverable date.

The first week is where most solo operators lose the client. Not because the work is bad. Because the process lived in their head and the week got busy.

This sequence takes 15 minutes the same day the money lands. Run it once and the week cannot erase it.

## The 4-minute log the minute payment clears

Open a note before you close the payment tab. Fill every blank.

```
Name: ________
Paid: ________ (date / time)
Amount: $________
Project / package: ________
Start date you named: ________
First deliverable: ________
Due date for first deliverable: ________
Welcome email sent: ________
Intake sent: ________
Kickoff booked: ________
Status: paid / onboarding / active
Next action: ________
```

Four minutes. Do it while the receipt is still open. If you wait until tomorrow the start date is already fuzzy.

## Minutes 5–10 — Send the welcome + intake

Subject: Welcome + next step for [Project name]

> Hi [Name],
>
> Payment received. You're in.
>
> Welcome email and intake are below. Fill the intake by [date 48 hours out] so I can lock the first deliverable for [date].
>
> [Paste the five intake fields below]
>
> Reply with any hard constraints on the start date and I'll confirm the calendar hold.
>
> Talk soon,
> [Your name]

One email. Welcome + intake + the date. Do not wait for a separate kickoff call to exist before this leaves.

After send: log the time. Set a 10-minute calendar block for 48 hours later labeled "Check intake: [Name]".

## Minutes 11–15 — Lock the first date and calendar

While the email is still open:

1. Write the first deliverable due date on the log.
2. Add a calendar block for that date titled "[Name] — [deliverable]".
3. Add the client to next Monday's "Active" row so the weekly reset sees them.
4. If they named a hard start constraint, reply in the same thread with the adjusted date. Do not open a new scope conversation.

Fifteen minutes total. The welcome is out. The intake is out. The first date exists outside your head.

## Exact fields the intake must collect

Keep it to these so they finish it:

- Preferred start window (next 7 days)
- One hard constraint (time zone, blackout date, or deliverable they need first)
- Who else needs to see the work (if anyone)
- Best email / Slack for status updates
- Anything already done that I should not redo

More than five questions and the intake sits unfinished. These five are enough to run the first week.

## Day-by-day first week (run the list, do not invent)

**Day 0 (payment day — the 15 minutes above)**

- Log filled
- Welcome + intake sent
- First deliverable date on calendar
- Client added to next Monday reset

**Day 1**

- Check the thread once. If they already replied with constraints, confirm the date in one line. Do not wait.

**Day 2 (48-hour mark)**

- Intake arrived: reply within 4 hours. Lock the start date. Name the one thing you need next. Mark status active.
- No intake: send the nudge. "Still want me to hold [date]? Reply with the intake or 'later' and I'll release the hold."

**Day 3–4**

- If intake is in, start the first piece only if the date is locked. Do not invent extra scope.
- If still silent after the day-2 nudge, one more line on day 4: "Holding [date] until end of day. Reply or I release it." Then stop.

**Day 5–7**

- Send the first short status if work has started: "Quick status: [what moved]. Next piece due [date]. Anything blocked on your side?"
- Add them to the Friday status slot if you run one. Same words every week.

Late is better than rewritten. If any day is missed, send the same line the same day you remember.

## Exact phrases that keep the week from collapsing

- Scope creep on day 1: "Happy to do that — it's $X and adds two days. Want me to add it or keep the original scope?"
- They ask for a call before intake: "Booked 15 minutes [day/time]. Please fill the five fields before the call so we use the time on decisions, not basics."
- Invoice or deposit question: "The [amount] already received covers [package]. First deliverable is locked for [date]."
- Quiet after welcome: use the day-2 hold-or-release line above. Do not write a new pitch.
