You open the laptop Monday with three clients, two quiet threads, and one invoice that never left. The week is already late. You start rebuilding the list from memory. That is the leak.

Do this instead. Twelve minutes. Same order every Monday. If you only have eight, stop after the cash moves.

## Minute 0–3 — Name the three cash moves

Write exactly three lines. Nothing else.

1. One delivery that is due or late this week
2. One follow-up that protects money (proposal, quiet client, or unpaid invoice)
3. One admin item that unblocks cash (contract, kickoff hold, or next invoice)

If a fourth appears, one of the three leaves. Put each on the calendar as a real block, even if it is only 20 minutes.

```
This week's three:
1) Deliver: ________ by ________  block: ________
2) Follow up: ________ (last touch ________)  block: ________
3) Unblock cash: ________  block: ________
Killed so these live: ________
```

Cash check: at least one of the three must be an invoice, a paid next date, or a proposal hold. If not, swap one in.

## Minute 3–7 — Touch every open client once

One line each. Next deliverable + next date. If you cannot name the date, that client is drifting.

```
Client 1: ________ — next: ________ by ________ — who owes: me / them
Client 2: ________ — next: ________ by ________ — who owes: me / them
Client 3: ________ — next: ________ by ________ — who owes: me / them
Quiet / no date: ________ → follow-up today or pause
```

Cap at paid clients plus any proposal that is still open. Old leads with no reply in 21 days are closed rows, not open work.

## Minute 7–11 — Send the two follow-ups

Usually one quiet proposal and one finished project with no check-in, or one unpaid invoice.

Proposal, quiet (day 5–7):

> Still want me to hold the [date] start, or should I release it? One line is enough.

Quiet after kickoff:

> Checking the files / access we named. First deliverable still set for [date]. Reply with the link or a new date.

Invoice that never left:

> Invoice for [deliverable] attached. Due [date]. Reply if the address is wrong.

Send two. Log the time. Do not draft a third.

```
Follow-up 1: ________ sent ________ — next if no reply: ________
Follow-up 2: ________ sent ________ — next if no reply: ________
```

## Minute 11–12 — Stop

Write tomorrow's first move in one line. Close the list.

```
Tomorrow first move: ________
Time box: ________
Done when: ________
```

If you keep going you will spend the morning organizing instead of shipping. The reset worked if the three cash moves exist on paper and two follow-ups left.

## Wednesday 4-minute check

Look at the three. Still the right three? If a fire ate one, replace it. Do not add a fourth.

Send any follow-up that is now overdue. One sentence each.

Put the Wednesday block on the calendar the same Monday you write the list. Unscheduled checks do not happen.

## Friday 4-minute close

Do not rebuild the week. Close it.

1. Mark which of the three moved.
2. Note the one that slid. It is next Monday's line 1 unless you kill it.
3. Send one close-out or one invoice if either is still open.

```
Moved: ________
Slid (next Monday line 1 unless killed): ________
Invoice or close-out sent: ________
```

## Extra moves when three clients already feel like six

- If any open invoice is older than 7 days, it becomes priority 3 before new delivery.
- After the two follow-ups, write the next touch date on the same card. Thursday cannot invent a different version.
- Cap the open-client scan at paid plus open proposals. Everything else is a closed or paused row.
- If the three priorities do not include one money move, swap one in before you leave the 3-minute block.
- Keep the fill-in blocks in the same place as the onboarding checklist and the proposal follow-up lines. One open, all available.
