# Client Onboarding Checklist

This is the real checklist. Not a summary. The actual steps.

## Before the kickoff call

- [ ] Contract signed and payment received (or deposit)
- [ ] Welcome email sent with date, time, and what to expect
- [ ] Intake form link sent — make them fill it out before you talk
- [ ] Calendar invite created with a clear agenda
- [ ] Any files or assets you need from them requested in writing

## The kickoff call

- [ ] Confirm goals in their words, not yours
- [ ] Confirm timeline and milestones
- [ ] Confirm what "done" looks like
- [ ] Confirm communication channel and response time
- [ ] Record or take notes — send a summary within 24 hours

## After the call

- [ ] Send the written summary
- [ ] Create the project in your system (folder, board, whatever you use)
- [ ] Set the first milestone date
- [ ] Send the first task or deliverable request
- [ ] Schedule the next check-in

## The rule

If you can't hand this checklist to a new hire and they can run onboarding without you, it's not done.
