# First Client 7-Day Sprint

This is the actual plan. Not motivation. The steps.

## Day 1: Pick your niche

- [ ] Choose one type of client you can help
- [ ] Write one sentence about what you do for them
- [ ] Find 10 people who fit

## Day 2: Build the offer

- [ ] Use the proposal template
- [ ] Set a price using the pricing worksheet
- [ ] Write a one-page landing page

## Day 3-4: Reach out

- [ ] Send 10 personalized messages
- [ ] Use the follow-up templates
- [ ] Don't take no personally

## Day 5-6: Close

- [ ] Send the proposal to anyone who replied
- [ ] Follow up with the breakup email if needed
- [ ] Get a yes or a clear no

## Day 7: Deliver

- [ ] Run the onboarding checklist
- [ ] Send the first deliverable
- [ ] Ask for a testimonial

## The rule

One client. One week. Start today.
