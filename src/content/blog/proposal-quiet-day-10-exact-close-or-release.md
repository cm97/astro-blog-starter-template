You sent the proposal. Day 3 and day 5 or day 7 nudges already went out. Still nothing. Now it is day 10. The start date you offered is either here or already passed. The calendar block is still sitting there. Every morning the open thread steals five minutes while you decide whether to send one more soft check-in.

Silence at day 10 is not a maybe. It is a file that has to be closed or released so the hours are free. Leaving it open trains you to carry ghosts into the next week.

## The 3-minute log before you send the day-10 close

Open the same note you use for the Monday scan. Fill this block.

```
Name: ________
Proposal sent: ________
Last nudge sent: ________
Start date offered: ________
Price: $________
Day 10 close due: ________
Status after send: replied / closed / released
```

If any field is blank, do not send. The close only works when the earlier dates are written.

## Exact day-10 close email — send today

Subject: Closing the file for [Project name]

> Hi [Name],
>
> Checking in one last time on the proposal from [date] for [one-line scope] at [price].
>
> I am releasing the [start date] today. If you still want it, reply with yes and I will send a fresh start date.
>
> Otherwise this file closes.
>
> [Your name]

One paragraph. No apology. No “let me know if you have questions.” The release is the close. A yes gets a new date. Silence frees the calendar.

Send it before 11am on a Tuesday, Wednesday, or Thursday. Never Friday. Never after 3pm.

Phone-paste version (under 160 chars):

> Closing the file on [project]. Releasing [start date] today. Reply yes if you still want a new date.

## What you do the minute it leaves

1. Mark the status “day 10 close sent” in the log.
2. Delete or move the calendar hold for that start date.
3. Write the next Monday scan row: “Day 10 close sent [Name]. File closed or waiting yes.”
4. Do not check the thread for 48 hours. If they reply yes, treat it as a new proposal and restart the clock with a fresh date.
5. If they pay, send the deposit confirmation and open the onboarding checklist the same hour.

## Extra concrete steps that stop the quiet file from living in your head

- Cap open proposals at five. Anything past day 10 without a reply gets this close. A sixth means you are rewriting the week.
- Copy the day-10 close into the same note as the day-3, day-5, and day-7 templates. One open, all available.
- After you send, set a 48-hour no-check rule. Looking early turns the close into another wait.
- If they reply “still thinking,” send one line: “Understood. The original date is released. Reply with yes and a preferred new window if you want a fresh proposal.” Do not leave the old file open.
- Never discount in the close. The original price stays the record. A new proposal can have a new price if scope changed.
- On the next weekly reset, move every proposal older than day 10 without a reply out of the active list. The list is for cash still open, not for ghosts.
- Write the exact release date into the email before you send. Guessing it from memory creates a soft close that does not free the calendar.
- Put a 4-minute calendar block titled “Day 10 close: [Name]” the night before. The block is the trigger. Without it the email never leaves.
- After the send, screenshot or copy the sent time into the log. “I think I sent it” is not a closed loop.
- If two day-10 closes land the same morning, send both before 11am. Do not spread them. One sitting, two files moved.
- Keep a “parked past day 10” note separate from the active list. One weekly scan of that note is enough.
- When a reply arrives, update the start date or close the file the same hour. Do not let a yes sit overnight.
- If they ask for a call, answer: “Happy to talk. First step is a short written yes on the original scope and price so we both know what we are discussing.” Do not jump on a call with an open maybe.
- At Friday close, count how many day-10 closes you sent that week. Write the number on the Monday still-open line. Zero open ghosts is the goal.
- Pre-write the day-10 subject and body in the calendar note the day the proposal first goes out. The 4-minute block only needs a paste and send.
- Never send the close from your phone while standing in a line. Sit, open the log, fill the three-minute block, then send. The log is the gate.
- After any paid yes, open the onboarding checklist the same hour. The follow-up sequence ends when money lands.
- Cap the hold window. After the named release date the original start date is no longer valid without a new proposal.
- If the original start date has already passed, do not offer to hold it again. The close is the release.
- Keep the five most common objection replies in the same note so you never search under pressure after a late reply.

## Exact replies for the day-10 replies you actually get

When they finally answer, do not invent a new email. Paste one of these.

**Still thinking / need more time:**
> Understood. Original date released. Reply with yes and a preferred new window if you want a fresh proposal.

**Can we hop on a call?**
> Happy to. First send a one-line yes on the original scope and price so we know what the call is about. Then pick a time.

**Price is high / can you do less?**
> Original price and scope stay the record. Reply yes if you want a fresh proposal with a new date.

**I need to check with [partner/boss]:**
> Got it. File closes today unless you reply yes. A yes gets a new start date.

**Send more info:**
> The proposal is the info. One line is enough: yes for a fresh date, or file closes.

**They pay:**
Open the onboarding checklist the same hour. Welcome, intake, kickoff hold. Do not celebrate first.
