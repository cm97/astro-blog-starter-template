Kickoff ends. They say they will send the files. Then nothing. Three days. Five. The first deliverable date is still on your calendar and their inbox is quiet.

That silence is where week one dies. You wait for the “right” moment. The moment never comes. The project drifts. Cash sits.

Send these instead. Same lines every time. No drafting from a blank screen.

## Day 3 — the short poke

Subject: Quick check — [project name]

> Hi [Name],
>
> Checking that the files / access we named on the kickoff are on the way.
>
> First deliverable is still set for [date]. Reply with the link or a new date if something is blocking it.
>
> [Your name]

One ask. One date. Send it on day 3 even if you feel awkward. Time box: 90 seconds. Copy the block, fill the two blanks, send.

## Day 7 — the decision line

Subject: Still holding [date] for [deliverable]?

> Hi [Name],
>
> Still holding [date] for the first deliverable, or should I move it so the slot is free?
>
> One line is enough. If the files are ready, reply with the link and we stay on the original date.
>
> [Your name]

This one forces a yes, a no, or a new date. Silence after this becomes a paused row, not an open one. Do not rewrite it. Paste, fill, send.

## Fill this before you close the laptop

```
Client: ________
Kickoff date: ________
First deliverable promised: ________ by ________
Day-3 sent: yes / no — time: ________
Day-7 sent: yes / no — time: ________
Next touch if still quiet: ________
Status: open / paused / closed
```

Print it or keep it in the same note as the onboarding checklist. Do not leave the dates in the email thread only.

## If they reply with a delay

Write the new date on the same card the same day. Do not leave it in the thread. Then put the new day-3 and day-7 on the calendar again. Reply once:

> Got it. New date is [date]. Day-3 and day-7 follow-ups reset to that. Original scope stays the same.

## Extra steps that stop the stall

- Log the kickoff date and the promised file list in the same place you log the first deliverable. If the file list is only in the Zoom chat, it vanishes.
- Set the day-3 and day-7 as calendar holds the same hour you finish the kickoff. Unscheduled pokes do not leave.
- If day 3 lands on a delivery-heavy day, send the poke before you open any other file. Ninety seconds.
- After day 7 silence, change the row from open to paused. Do not keep it in the “active” list. Active means you still expect a reply this week.
- On the next Monday reset, scan for any paused rows older than 14 days. One line: “Still paused or close?" Send or archive.
- Never send a third novel. The two lines above are the whole set. A third email is how you start negotiating with yourself.
- If they reply with the files on day 4, still log the original date and the actual arrival date. The gap is the data for the next client.
