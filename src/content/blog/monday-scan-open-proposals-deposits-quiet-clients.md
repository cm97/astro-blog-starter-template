Monday starts and the open proposals, unpaid deposits, and quiet clients all live in different tabs. By 11am one of them has already aged past the window where a short email still works.

You do not need a new CRM. You need one 15-minute scan that surfaces the three people who need a message today so the rest of the week does not depend on you remembering them.

## The 15-minute Monday scan

Open a blank note or the Today screen. Write these three rows. Cap each at three names. More than that is noise.

```
Open proposals past day 5: ________  ________  ________
Unpaid deposits past day 2: ________  ________  ________
Quiet clients (no reply 7+ days mid-project): ________  ________  ________
```

Fill only the ones that are actually due. If a row is empty, write none. Do not invent names to feel busy.

Time box the whole scan at 15 minutes. If you go over, the emails do not leave.

## Exact next action for each row

**Open proposals past day 5**

Send the binary:

> Still want me to hold the [start date] for [project], or should I release it?

Subject: Re: [Project name]

One sentence. Mid-morning before 11am. Log the send time. Do not check for 24 hours.

Fill-in you paste:

```
To: ________
Subject: Re: ________
Body: Still want me to hold the [start date] for [project], or should I release it?
Sent: ________
```

**Unpaid deposits past day 2**

Send:

> Invoice for the [project] deposit is in your inbox. Still good to lock the [start date], or should I release it?

Same window. Same log. Do not start work.

Exact paste:

```
To: ________
Subject: Deposit for [project]
Body: Invoice for the [project] deposit is in your inbox. Still good to lock the [start date], or should I release it?
Amount still open: $________

```

**Quiet clients 7+ days mid-project**

Send:

> Quick check on [project]. Still on track for [next milestone date], or do you need me to hold?

One line. Before 11am. Update the next touch date the second it leaves.

Paste version:

```

Subject: Quick check on [project]
Body: Quick check on [project]. Still on track for [next milestone date], or do you need me to hold?

```

## The log that survives Thursday

After each send, fill this in the same note:

```
Name: ________
Row: proposal / deposit / quiet
Touch sent: ________ (date/time)
Next check: ________
Status: waiting / replied / closed
Open cash: $________
```

Three minutes total. The scan is useless if the next date is blank.

## Day-by-day after the scan (do not invent new lines)

**Monday (scan day)**
- Rows filled, three max.
- Emails sent before 11am.
- Next check dates written.

**Tuesday**
- Do not re-check the same three. Delivery only.
- If a reply lands, update status in 60 seconds. Do not rewrite the email.

**Wednesday**
- If any next-check is today, send the same line again or the hold-or-release. One line.
- Cap at the original three. New quiet names wait until next Monday.

**Thursday–Friday**
- If still no reply on a deposit or proposal past the next check, mark closed or move to next Monday list.
- Do not write a fourth paragraph. The binary already did the job.

Late is better than a new draft. Send the same line the day you remember.

## Extra cash protectors for the Monday scan

- Write the open dollar amount next to every name before you rank. Cash decides order, not who you like.
- Cap each row at three. A fourth name is noise that kills the send.
- Pre-write the three bodies the night before if Monday mornings are slammed. The blanks are the only edit.
- If a deposit is past day 2 and you already sent the line once, the second send is the same sentence plus "releasing the start date Friday if no reply."
- After the scan, add one line to the weekly reset: "Monday scan done. Next scan: ________". Silence after the scan is how proposals die.
- Never start work on a quiet client or unpaid deposit. The scan is the gate.
