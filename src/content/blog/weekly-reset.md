You set up a clean process on Monday. By Thursday it's a corpse. This is the reset that survives.

## The 20-minute reset

- **5 min** — Clear the inbox to zero. Archive, delete, or reply. No "later" pile.
- **5 min** — Review the three priorities. Kill one. Keep two.
- **5 min** — Check follow-ups. Who's waiting on you? Send one message.
- **5 min** — Write tomorrow's first task. One line. Done.

Do it every Friday. Same time. Same place. It becomes muscle memory.
