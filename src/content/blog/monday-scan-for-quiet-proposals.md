Proposals go quiet. You notice on Thursday when it is already awkward.

The fix is a Monday scan that takes 20 minutes and catches them while the conversation is still warm.

## Why proposals die in silence

You sent the proposal. They said they needed a few days. Five days turn into twelve. You open the thread, feel the awkward, and close it again. By the time you write something, the lead has already hired someone else or the budget moved.

The problem is not the proposal. The problem is that the next action lives only in your head. Heads forget when delivery is loud.

## The 20-minute Monday scan

Do this every Monday (or the first 20 minutes of your week). Same order every time. Stop when the timer hits 20.

1. Open the list of every proposal sent more than 5 days ago with no reply.
2. For each one, send the day-5/7 follow-up if none exists yet.
3. Log the send date next to the name. Set the next check for 3 days later.
4. If still silent after the bump, send the break-up on day 14 and close the file.
5. One past client from last quarter gets the re-engagement note (optional if time remains).

That is the entire process. Five actions max. Twenty minutes. The emails are already written.

```
Date: ________
Proposals older than 5 days: ________

Break-ups sent: ________
```

## Exact emails that do the work

**Day 5–7 proposal follow-up**
Subject: Re: [Project] proposal

Hi [Name],

Following up on the proposal I sent [day] for [project].

Is this still something you want to move forward with, or should I take it off my plate?

Happy to adjust scope or timeline if anything changed.

[Your name]

**Day 10–12 second bump (only if needed)**
Subject: Re: [Project] proposal

Hi [Name],

Quick bump on the [project] proposal. Still useful, or should I close it on my side?

[Your name]

**Break-up / close the loop (day 14+)**
Subject: Closing the loop on [project]

Hi [Name],

I have not heard back on the proposal from [date]. I am closing this out on my side so the calendar stays clear.

If timing changes later, reply and I will reopen it.

[Your name]

**Re-engagement for a past client (if time left)**
Subject: Checking in after [project]

Hi [Name],

It has been a while since we wrapped [project]. Curious if anything new came up that matches what we did before.

Happy to hop on a short call this week if useful.

[Your name]

These four cover the silence that kills cash.
