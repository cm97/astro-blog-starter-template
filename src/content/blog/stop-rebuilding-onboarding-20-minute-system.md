A new client pays. You spend the next two hours hunting old emails for a welcome message, an intake form, and a kickoff agenda. By the time you send something, the momentum is gone and the week is already late.

That rebuild happens every time because the process lives only in your head. Heads forget when delivery is loud.

## The failure mode that costs the first week

You closed the deal. The deposit landed. Then silence while you dig for the last welcome email you wrote three months ago. You paste pieces together, change the name, and send it late. The client starts with a slow first impression. You start with less time for the actual work.

The fix is a 20-minute sequence that already exists before the payment hits. Same steps, same order, every client.

## The 20-minute onboarding sequence

Run this the same day the deposit lands, or first thing the next morning. Timer on. Stop at 20 minutes.

1. Send the welcome email with the exact next step and the intake link or form.
2. Confirm the kickoff call time or send the calendar link if none is set.
3. Create the private client note with the project name, start date, and three key outcomes.
4. Add the client to the weekly reset list so they appear on Monday without hunting.
5. Set the first mid-project check-in date (day 7 or day 10).

Five actions. Twenty minutes. The emails and form already exist.

**Kickoff confirmation (day of or day before)**
Subject: Kickoff tomorrow — [project]

Hi [Name],

Confirming kickoff at [time] [link]. Agenda is the three outcomes from the intake plus any open questions.

See you then.

[Your name]

These three cover the first 48 hours. Nothing is rebuilt from memory.

## Extra concrete steps that keep the first week clean

- Send the welcome the same calendar day the payment clears. Delay past 24 hours and the client starts wondering if you are still on it.
- Paste the intake link in the private note the moment you send it. Next time you open the note the link is there.
- Cap the welcome email at five sentences. Longer versions get rewritten under pressure and never ship.
- If they reply with access details instead of the form, copy the key points into the note and still ask for the form. Do not skip the record.
- Add the first check-in as a calendar hold titled "[Client] day-7 check" so the weekly reset finds it without searching.
- If the client is in a different time zone, state the kickoff time in both zones in the confirmation email.
- Screenshot or copy the three sent items into the same note the weekly reset opens. The sequence disappears if it only lives in sent mail.
- If they have not filled the intake by day 3, send the day-2 nudge once and then wait for the kickoff. Do not chase three times.
- Log the exact subject lines you used. Next client will not require a rewrite.
- End the 20 minutes by confirming the client now appears on the weekly list. If they do not, the Monday scan will miss them.
