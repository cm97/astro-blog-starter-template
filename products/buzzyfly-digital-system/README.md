# Buzzyfly Digital System
### The complete operating framework for coaches and solo service providers.

---

## What you have

| Folder | What's inside |
|---|---|
| `checklists/` | Six ready-to-run process checklists |
| `templates/` | Six fill-in email and document templates |
| `scripts/` | Word-for-word scripts for hard conversations |

**Run these in order for a new client:**
1. `checklists/intake.md` — before you ever get on a call
2. `checklists/onboarding.md` — once they sign and pay
3. `templates/welcome-email.md` — send within 1 hour of payment
4. `checklists/weekly-reset.md` — run every Monday, 20 minutes
5. `checklists/follow-up.md` — anytime a lead or client goes quiet
6. `scripts/scope-guard.txt` — anytime they ask for more than you agreed

---

## How to use this system

**Do not customize everything on day one.** Pick the one checklist that fixes your biggest problem right now. Run it once. Then run it again. Then add the next one.

The system works because it's the same every time — not because it's perfect.

## Quick-start by problem

| Your problem | Start here |
|---|---|
| Clients keep ghosting after proposals | `checklists/follow-up.md` + `templates/check-in-email.md` |
| Onboarding takes too long and varies every time | `checklists/onboarding.md` + `templates/welcome-email.md` |
| Clients keep asking for more than they paid for | `scripts/scope-guard.txt` + `checklists/scope-creep.md` |
| You lose track of clients between deliverables | `checklists/retention.md` |
| Monday mornings feel chaotic | `checklists/weekly-reset.md` |
| You're not charging enough | `templates/pricing-worksheet.md` |
